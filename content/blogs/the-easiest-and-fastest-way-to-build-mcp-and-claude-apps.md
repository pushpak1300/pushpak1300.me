This Laravel article introduces MCP Apps support in laravel/mcp, a way for MCP tools to return interactive HTML interfaces instead of text, rendered inline inside the conversation.

It walks through scaffolding an app with one Artisan command, wiring Tailwind and Alpine automatically, keeping implementation-detail tools hidden from the model, and two real examples built on Locket.
